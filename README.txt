ТИХИЕ ЗАМЕТКИ — локальный редактор Markdown

ЗАПУСК НА WINDOWS
1. Распакуйте ВЕСЬ архив в постоянную папку, например Документы\Тихие заметки.
2. Откройте index.html в Яндекс Браузере: правой кнопкой → Открыть с помощью.
3. Интернет, аккаунт, Node.js и установка приложения не нужны.
4. После открытия создайте тестовую заметку, дождитесь «Сохранено в браузере»,
   закройте страницу и откройте её снова. Убедитесь, что текст сохранился.
   Добавьте фото и тоже проверьте после закрытия и открытия.

ВАЖНО О ДАННЫХ
Заметки и фото сохраняются в IndexedDB вашего браузера, а не автоматически
в папку Windows. Они привязаны к браузеру, профилю и адресу index.html.
Не используйте инкогнито. Не перемещайте приложение без резервной копии.
Очистка данных браузера или смена профиля может удалить заметки.
Регулярно: Экспорт → Резервная копия. Храните скачанный ZIP отдельно.
Если показано «Не сохранено», не закрывайте страницу: выгрузите данные
через Экспорт. Ошибка добавления фото означает, что фото НЕ сохранено:
сохраните оригинал и повторите добавление после решения проблемы.
Не открывайте несколько копий приложения одновременно. При наличии
Web Locks второе окно блокируется для защиты от перезаписи.

ПЕРВАЯ ЗАМЕТКА
«＋ Заметка» → введите название → пишите текст. Кнопки форматирования
добавляют Markdown. «Просмотр» показывает результат. На узком экране
переключайтесь между «Редактор» и «Просмотр».
«＋ Папка» создаёт папку; выберите её в поле папки выбранной заметки.
Папки можно вкладывать: Работа/Идеи. Пустые папки не имеют файлов в ZIP.
Теги вводятся через запятую. Звезда добавляет заметку в избранное.
Удаление перемещает в корзину: выберите «Корзина» и «Восстановить».

ФОТО И ССЫЛКИ
«Фото» выбирает PNG, JPEG или GIF и спрашивает описание.
Можно перетащить фото на редактор или вставить из буфера, если браузер
передаёт картинку. Исходные файлы не сжимаются и не изменяются.
В Markdown записывается ![Описание](attachments/уникальное-имя.png).
В ZIP для заметок внутри папок пути автоматически получают ../.
Внешние изображения не загружаются без нажатия «Разрешить».
[[Название]] связывает заметки. [[Папка/Название]] устраняет совпадения.
Ссылка на отсутствующую заметку предлагает создать её. Переименование
обновляет однозначные внутренние ссылки. Неоднозначные требуют выбора.

ЭКСПОРТ И ИМПОРТ
Экспорт → «Скачать заметку .md» или «Скачать .txt» даёт текст UTF-8.
Сам .md НЕ содержит фотографии. ZIP заметки включает её папку и картинки;
распакуйте целиком. «Скачать все заметки» сохраняет активные заметки.
«Резервная копия» включает также корзину, теги, избранное и настройки.
«Импорт» принимает .md, .txt, ZIP заметок и резервные копии.
Обычный импорт добавляет данные; совпадения названий получают суффиксы.
Восстановление резервной копии ЗАМЕНЯЕТ текущее хранилище после подтверждения.
Сначала сохраните текущую резервную копию. Импорт архива записывается
атомарно: ошибка не должна оставлять частично восстановленное хранилище.
ZIP-импорт поддерживает UTF-8 Markdown и PNG/JPEG/GIF, до 100 МБ в архиве
и до 250 МБ после распаковки, не более 10000 файлов.
«Печать / PDF» печатает просмотр; PDF выбирайте в диалоге браузера.

ДЛЯ НЕЙРОСЕТИ
«Для нейросети» → выберите заметки → при желании включите связанные
(по умолчанию выключено) или объединение в один Markdown → «Показать
итоговый список файлов» → исключите лишнее → скачайте ZIP.
Объединённый Markdown находится внутри ZIP вместе с изображениями.
При исключении фотографии её ссылка в тексте остаётся: проверяйте список.
Приложение не подключается к API и не отправляет данные нейросети.
Самостоятельно загрузите материалы в выбранный сервис. Некоторые сервисы
не принимают ZIP: распакуйте и загрузите Markdown и фотографии отдельно.

СОВМЕСТИМОСТЬ И ПРОВЕРКИ
Целевая система: Windows 10 Pro 22H2, 32-бит, Яндекс Браузер 25.6.0.2372.
Использованы обычные HTML/CSS/JavaScript и встроенный IndexedDB; нет
64-битного исполняемого файла или обязательного серверного компонента.
Библиотеки marked 12.0.2, DOMPurify 3.2.7, JSZip 3.10.1 входят в vendor,
их лицензии находятся рядом. Обязательных внешних запросов нет.
Проверено автоматизированно в Chromium на Linux через локальный HTTP:
русские заметки, Markdown, защита от HTML-скриптов, сохранение при reload,
два фото с одинаковыми именами, ZIP и относительные пути из вложенных папок,
импорт Markdown и ZIP, резервная копия и восстановление, обновление ссылок,
поиск/теги/избранное/корзина, AI-экспорт, ошибка квоты и аварийный экспорт.
Открытие file:// в облачном Chromium блокируется политикой этой среды.
Работа именно на вашей Windows и в Яндекс Браузере пока НЕ подтверждена.
Проверьте запуск и сохранение по шагу 4. Если браузер блокирует IndexedDB
для локального файла, напишите точный текст ошибки: не храните важные
данные до проверки. Для временной работы можно писать и скачивать .md.
Запасной запуск: дважды нажмите START-LOCAL.bat. Он использует встроенный
в Windows 10 PowerShell, открывает браузер и обслуживает файлы только на
вашем компьютере (127.0.0.1:8811). Окно оставьте открытым; закрытие
останавливает сервер. Ничего устанавливать или вводить в терминал не нужно.
Если системная политика блокирует PowerShell, не обходите её: сообщите
об ошибке. Этот запасной запуск не проверен на Windows в облачной среде.
Для него будет отдельное хранилище; переносите заметки резервной копией.

ОГРАНИЧЕНИЯ
Нет синхронизации, аккаунтов, плагинов, графа и записи в произвольную папку.
Изображения подгружаются при приближении к видимой области.
Не используйте этот редактор как единственный архив важных документов.
Нет поддержки всех расширений Obsidian и произвольных бинарных вложений.
Поддерживаются встроенные картинки Markdown вида ![подпись](путь),
а не Obsidian-специфичный синтаксис ![[фото.png]]. Сложные reference-images
и HTML-картинки не поддерживаются. Импорт текста — UTF-8; файлы старых
кодировок нужно предварительно сохранить в UTF-8.
